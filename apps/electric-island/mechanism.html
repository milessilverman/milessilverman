How one node works

Any switch can always open. Closing has to earn it.

Each node is a switch with two small computers. The safety chip can always open it, on its own. Closing needs every check to pass, the handle up and no padlock. Computers can ask a node to close, but never force it, and never switch a home off.

02

Inside the node

The switch has two coils: one opens it, one closes it. Who can fire each one is the whole safety design.

The handle and padlock are physical gaps in the close wire, so no bug or hacked command can bridge them. The trip coil runs on a supercapacitor, so opening works even with no power anywhere.

The 8 checks before any switch closes

  1. No padlock on the handle
  2. No fault lockout, and a clean test pulse if the far side is dead
  3. A signed, unexpired request, or the handle pushed up
  4. At least 15 seconds since this switch last moved
  5. Voltage difference within limits
  6. Frequency difference within limits
  7. Waves lined up (phase angle) within limits
  8. Enough steady power on every phase: 115% of the load

Limits from IEEE 1547 tighten as islands grow: 0.3 Hz, 10% and 20° under 500 kVA; 0.2 Hz, 5% and 15° up to 1.5 MVA; 0.1 Hz, 3% and 10° above that.

Try it: line up the waves before closing

Before closing, the node compares the street's voltage wave with the home's. If they are out of step when the contacts meet, a surge rips through both sides. Set how far apart the two sides are, then ask the node to close. It waits until the waves line up within 20°. The 60 Hz wiggle is frozen so you can see the shapes; the drift between them runs at real speed.

04

Manual override

Every node has the same handle and its own padlock hasp, from the home switch to the power-line recloser. Section nodes also get a visible-break disconnect for crews.

Handle down: open

A lever pulls the contacts apart. No chip or battery involved, so it always works. Anyone can do it.

Down with a padlock: locked

The hasp holds the handle down and the close wire is cut. Only the padlock's owner can release it.

Handle up: asks to close

Up doesn't touch the contacts. It asks the node to close, and the node runs the same 8 checks. Amber means waiting, with the reason shown.

05

Rules no computer can change

The key rules live in hardware or the safety chip's factory-fixed program, not in software anyone can update.

  • Opening never needs permission. Two separate paths, neither waits for a message.
  • A padlock blocks closing. It physically cuts the close wire.
  • No computer can switch a home off. Only its own readings, the handle or a padlock can.
  • Never join two sides out of step. Both chips must agree the waves line up.
  • Never power a dead line blind. A test pulse must come back clean first.
  • Emergency energy can't be sold. The island battery's floor only discharges while cut off from the grid.

06

The hard problems, and the plan for each

Islanding is the easy part. These make it safe on real wires.

  • PhasesStreets sit on different phases, so they join over the power line only with a three-phase leader like the base.
  • Faults inside an islandBatteries can't blow a fuse, so nodes compare current in and out and trip within 60 ms.
  • Crew safetyA padlock on every node, visible-break disconnects, and grounds that fail every test pulse. Lockout rules get written with the utility.
  • Batteries on utility wiresThe utility runs the bigger nodes and island batteries. Home batteries and EVs join through its program.
  • InrushAn island battery ramps a dead transformer's voltage up over about a second.
  • Cold-load pickupHomes rejoin one at a time; each AC waits a random 0 to 5 minutes.
  • Two closes at onceEach island approves one close at a time, so no spare power is counted twice.
  • Leader failureEvery battery helps hold the grid, so the next one takes the lead in about 20 ms.

Inrush, leader handover and phase balance still need a circuit model and bench tests.
